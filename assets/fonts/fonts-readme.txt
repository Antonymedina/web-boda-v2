Local font files required for this project

Download these fonts in .woff2 format and place them in this folder with these exact file names:
- ./assets/fonts/PlayfairDisplay-Regular.woff2
- ./assets/fonts/PlayfairDisplay-Bold.woff2
- ./assets/fonts/PlayfairDisplay-SemiBold.woff2
- ./assets/fonts/Archivo-Light.woff2
- ./assets/fonts/Archivo-Regular.woff2
- ./assets/fonts/Archivo-Medium.woff2

Font usage:
- Titles: Playfair Display
- Body text: Archivo

Important:
- The CSS is already configured to load these exact file names.
- For maximum visual fidelity in editorial sections, add:
  - PlayfairDisplay-Bold.woff2
  - Archivo-Light.woff2
- If the files are missing, the site will fall back to:
  - Playfair Display, Georgia, serif
  - Archivo, Arial, sans-serif
- Local fonts are prioritized so the site can work cleanly when opened directly with file://
